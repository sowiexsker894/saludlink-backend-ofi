# Aportes Dev 3 - Módulo IA SaludLink

## Backend

Como Dev 3, mi participación se enfoca en la implementación del módulo de inteligencia artificial relacionado con citas médicas y agenda médica.

## Funcionalidades asignadas

- Implementación del asistente de citas con IA.
- Integración del endpoint POST /api/ai/appointment.
- Integración del reporte institucional GET /api/ai/report.
- Implementación del asistente de agenda médica.
- Integración del endpoint POST /api/ai/schedule.

## Flujo de trabajo

El trabajo se realiza usando GitFlow, creando ramas feature desde develop y subiendo commits propios a GitHub para evidenciar la participación individual.

## Herramientas utilizadas

- Java con Spring Boot para backend.
- PostgreSQL y Docker para base de datos local.
- Postman para pruebas de endpoints.
- Git y GitHub para control de versiones.
